# Security Policy

Hark runs entirely on your Mac. There is no server side, no account and no
telemetry, so most classic attack surface simply does not exist here. What
remains is the app itself: it listens to the microphone, types into the
focused app and reads a watched file aloud.

## Reporting a vulnerability

If you find a way to make Hark do more than it should (for example: a
crafted file or message that executes something, escalates permissions, or
leaks audio), please report it privately: open a GitHub issue titled
"SECURITY" WITHOUT technical details, and I will get in touch so you can
share the specifics privately. Please give me a few days before publishing
anything.

Reports are read with priority. The fix ships as a normal release; the
release notes credit you if you want that.

## Supported versions

Only the latest release receives fixes.
